# 书海回响（Book Echoes）项目运行逻辑总结报告

## 一、项目概述

书海回响是一个基于上海图书馆借阅数据的书目推荐项目，采用 Next.js 15 构建的现代化 Web 应用。该项目以杂志封面式布局展示每月精选书籍，提供三种浏览模式：期刊详情页（散点画布）、往期归档、随机漫步。

### 核心特性
- **杂志式封面布局**：最新3期以扇形卡片展示，历史期刊按年份归档
- **3D 交互效果**：卡片支持鼠标跟随倾斜、拖拽、聚焦等交互
- **文件系统即数据库**：所有数据存储在 `public/content/` 目录，无需数据库
- **静态生成 + ISR**：页面静态预渲染，数据每小时增量更新

### 3.3 核心数据结构

```typescript
// 书籍数据结构
interface Book {
    id: string;                    // 条码
    month: string;                 // 来源标识
    title: string;
    subtitle?: string;
    author: string;
    translator?: string;
    publisher: string;
    pubYear: string;
    rating: string;                // 豆瓣评分
    callNumber: string;            // 索书号
    doubanLink?: string;
    isbn?: string;
    series?: string;
    recommendation: string;        // 推荐语
    reason?: string;               // 初评理由
    summary: string;               // 内容简介
    authorIntro: string;           // 作者简介
    catalog: string;               // 目录
    coverUrl: string;              // 封面图 URL
    coverThumbnailUrl?: string;    // 封面缩略图
    cardImageUrl?: string;         // 卡片图
    cardThumbnailUrl?: string;     // 卡片缩略图
    originalImageUrl?: string;     // 原图
    originalThumbnailUrl?: string; // 原图缩略图
}

// 归档项结构
interface ArchiveItem {
    id: string;            // 目录名
    label: string;         // 显示名称
    type: 'month' | 'subject' | 'sleeping_beauty';
    previewCards: string[]; // 预览图数组
    bookCount: number;
    books: Book[];
    vol?: string;          // 期号
}

// 年份归档数据
interface YearArchiveData {
    year: string;
    months: ArchiveItem[];
    subjects: ArchiveItem[];
    sleepingBeauties: ArchiveItem[];
}
```

## 四、页面运行逻辑详解

### 4.1 首页 (`/`)

```
首页渲染流程
│
├── 数据获取
│   └── getMonths() → 获取所有月份数据
│       └── 扁平化为数组，按时间倒序
│
├── 数据分配
│   ├── latestMonth (最新1期)
│   └── images (最新期刊的书籍图片)
│
├── 组件渲染
│   └── HomeHero
│       ├── 轮播背景图 (6秒切换)
│       ├── 书法标题动画 ("书海回响")
│       └── Enter Issue 按钮
│
└── 导航入口
    ├── 点击标题/按钮 → /2025-11 (最新期刊页)
    └── HomeNavigation → /archive (归档页)
```

### 4.2 期刊详情页 (`/[month]`)

```
期刊页渲染流程
│
├── 解析月份参数
│   ├── 普通月份: "2025-08"
│   ├── 睡美人: "2025-sleeping-2025-08"
│   └── 主题卡: "2025-subject-数字遗产-舞蹈"
│
├── 数据获取
│   └── getMonthData(month)
│       ├── 读取 metadata.json
│       └── 转换 Book 对象数组
│
├── Canvas 组件初始化
│   ├── 设置 viewMode = 'canvas'
│   ├── 设置 selectedMonth
│   └── 解析 URL focus 参数
│
├── 书籍散点布局计算
│   └── seededRandoms(bookId, 3)
│       ├── x: 0-1 随机位置
│       ├── y: 0-1 随机位置
│       └── rotation: -15~15 度
│
├── 交互状态管理
│   └── useStore
│       ├── focusedBookId: 选中书籍
│       └── scatterPositions: 拖拽位置
│
├── 用户交互流程
│   ├── 悬停 → 预览卡片浮起
│   ├── 点击 → 展开 InfoPanel
│   ├── 拖拽 → 移动卡片位置
│   ├── 点击 InfoPanel 导航 → 切换书籍
│   └── 点击关闭 → 返回散点模式
│
└── 退出清理
    └── clearScatterPositions()
```

### 4.3 归档页 (`/archive`)

```
归档页渲染流程
│
├── 数据获取
│   └── getArchiveData()
│       └── 按年份分组所有内容
│
├── ArchiveContent 组件
│   ├── 年份导航 (左侧边栏)
│   │   └── 优先显示当前年份
│   └── Tab 切换 (月份牌/睡美人/主题卡)
│
├── 内容展示
│   ├── 月份牌: 按月展示卡片网格
│   ├── 睡美人: 延迟出版书籍专题
│   └── 主题卡: 按主题分组展示
│
└── 交互
    └── 点击卡片 → /{item.id}
```

### 4.4 随机漫步页 (`/random`)

```
随机漫步页渲染流程
│
├── 数据获取
│   └── getAllBooksRandomized()
│       └── 收集所有书籍并打乱顺序
│
├── RandomMasonry 组件
│   ├── 瀑布流布局 (3列)
│   ├── 高度变化 (4种变体循环)
│   └── 背景漂浮线条动画
│
├── 交互
│   ├── 点击书籍 → /{book.month}?focus={book.id}
│   └── Shuffle 按钮 → 重新随机排序
│
└── 导航
    └── 顶部导航栏 (首页/往期)
```

```typescript
}
```

### 7.1 图片资源 API

```
GET /api/images/{month}/{id}/{type}

参数:
├── month: 期刊标识
│   ├── 普通月份: 2025-08
│   ├── 睡美人: 2025-sleeping-2025-08
│   └── 主题卡: 2025-subject-数字遗产-舞蹈
├── id: 书籍条码
└── type: 图片类型
    ├── card       → 卡片图 {id}.png
    ├── thumbnail  → 卡片缩略图 {id}.png
    ├── cover      → 封面图 pic/cover.jpg
    └── cover-thumbnail → 封面缩略图 pic/cover_thumb.jpg

响应:
└── 图片文件流 (支持缓存 1 年)
```

### 7.2 MD 文件列表 API

```
GET /api/list-md-files?year={year}&subject={subject}

参数:
├── year: 年份 (如 2025)
└── subject: 主题目录名

响应:
└── JSON: ["主题文章1.md", "主题文章2.md", ...]
```

## 九、性能优化策略

### 9.1 渲染优化

| 优化点 | 实现方式 |
|-------|---------|
| 静态生成 | `export const dynamic = 'force-static'` |
| ISR 缓存 | `export const revalidate = 3600` (1小时) |
| 图片懒加载 | Next.js Image 组件 `loading="lazy"` |
| 关键图片优先 | 前3本书使用 `priority={true}` |
| 按年分页 | 归档页仅渲染当前年份数据 |

### 9.2 运行时优化

| 优化点 | 实现方式 |
|-------|---------|
| 拖拽位置缓存 | Zustand store 持久化散点位置 |
| 鼠标事件节流 | `requestAnimationFrame` 降频 |
| Hydration 避免 | 预计算随机值 + `suppressHydrationWarning` |
| 字体优化 | 动态加载 + R2 CDN 分发 |

### 9.3 资源优化

- **字体**：Web Font 优化，字体文件压缩为 woff2
- **图片**：Cloudflare 图片加载器自动压缩
- **缓存**：API 响应缓存 1 年 (`Cache-Control`)

## 十一、总结

书海回响项目采用 Next.js App Router 构建，形成了一个高效、优雅的书目展示平台。其核心设计理念包括：

1. **文件系统即数据库**：简化部署，无需数据库运维
2. **静态生成 + ISR**：兼顾性能与数据更新
3. **杂志式视觉设计**：提升用户体验与内容吸引力
4. **组件化架构**：易于维护与扩展
5. **流畅的交互体验**：3D 动效与拖拽交互增强沉浸感

整个系统的数据流清晰、状态管理集中、组件职责明确，是一个值得参考的现代化 Web 应用案例。
