## 一、物理引擎与"活化"实现

### 1.1 散落布局的数学模型

在 [`Canvas.tsx`](components/Canvas.tsx:144) 中，书籍散落布局采用**确定性伪随机算法**实现，确保同一本书每次刷新都落在相同位置：

```typescript
// lib/seededRandom.ts
export function seededRandoms(seed: string, count: number): number[] {
    // 使用书籍条码作为种子，确保位置确定性
    const results: number[] = [];
    for (let i = 0; i < count; i++) {
        results.push(seededRandom(`${seed}-${i}`));
    }
    return results;  // [randX, randY, randRot] ∈ [0, 1]
}
```

**布局参数设计**：
| 参数 | 计算公式 | 取值范围 | 设计意图 |
|-----|---------|---------|---------|
| x 坐标 | `randX * maxW` | 0 ~ 屏幕宽度-卡片宽度 | 水平随机分布 |
| y 坐标 | `randY * maxH` | 0 ~ 屏幕高度-卡片高度 | 垂直随机分布 |
| 旋转角度 | `randRot * 30 - 15` | -15° ~ +15° | 模拟书本散落的自然倾角 |

**避让算法**（[`BookCard.tsx`](components/BookCard.tsx:69)）：
```typescript
// 避开左下角 Dock 区域
const isBottomLeft = x < maxW * 0.4 && y > maxH * 0.6;
if (isBottomLeft) {
    x += maxW * 0.4;  // 向右偏移
}
```

### 1.2 拖拽物理交互

拖拽实现采用 Framer Motion 的物理弹簧模型：

```typescript
// ScatterCard.tsx:99-118
<motion.div
    drag
    dragMomentum={false}      // 禁用惯性，保持精准控制
```

| 参数 | 值 | 效果描述 |
|-----|---|---------|
| stiffness | 80 | 中等刚度，回弹速度适中 |
| damping | 15 | 低阻尼，保留一定摆动 |
| dragElastic | 0.1 | 边界处的轻微回弹提示 |

### 1.3 "活化智慧遗珠"的视觉隐喻表达

物理引擎通过以下设计表达"遗珠散落"的隐喻：

1. **散落初态**：首次加载时卡片从 `scale: 0.9, opacity: 0` 渐显入场（[`ScatterCard.tsx`](components/BookCard/ScatterCard.tsx:76)）
2. **随机分布**：每本书有独特的旋转角度（-15°~15°），模拟散落桌面的自然感
3. **可干预性**：用户可以拖拽书籍重新排列，象征"发掘"和"整理"的动作
4. **确定性回位**：拖拽结束后位置被记录在 Zustand Store 中，下次访问保持用户的整理成果

### 3.2 视觉质量与渲染性能的权衡

| 优化策略 | 实现方式 | 性能收益 |
|---------|---------|---------|
| 图片懒加载 | `loading="lazy"` + 前3本 `priority` | 减少初始加载量 |
| 缩略图优先 | 先加载 `coverThumbnailUrl` | 降低网络带宽 |
| 事件节流 | `requestAnimationFrame` 降频 | 减少 CPU 占用 |
| CSS 硬件加速 | `transform` + `opacity` | GPU 加速渲染 |
| 散点交错入场 | `delay: index * 0.02` | 分散渲染压力 |

**关键代码位置**：
- 图片懒加载：[`ScatterCard.tsx`](components/BookCard/ScatterCard.tsx:135) `loading={index < 6 ? 'eager' : 'lazy'}`
- 优先级加载：[`ScatterCard.tsx`](components/BookCard/ScatterCard.tsx:136) `priority={index < 3}`
- 散点交错延迟：[`ScatterCard.tsx`](components/BookCard/ScatterCard.tsx:118) `delay: index * 0.02`

| 性能优化 | RAF 节流 + CSS 硬件加速 | 60fps 流畅体验 |
| 图像优化 | Next.js Image | 自动懒加载 + 格式优化 |

### 5.3 设计理念总结

通过以上技术实现，"书海回响"项目实现了：

1. **空间隐喻**：从目录柜（首页）→ 散落桌面（期刊页）→ 工作台（详情页）的空间叙事
2. **物理交互**：拖拽、弹簧、回弹等物理效果增强沉浸感
3. **活化表达**：用户可以主动"发掘"散落的书籍，通过整理行为赋予书籍新的秩序
4. **性能平衡**：通过渐进式加载、事件节流、硬件加速等技术手段，在视觉丰富度与性能之间取得平衡

这些技术细节共同支撑了"博物馆级沉浸式 Web 交互"的设计目标，让书目推荐从静态列表转变为可探索的数字展览空间。
