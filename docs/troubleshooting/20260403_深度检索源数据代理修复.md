# 故障复盘报告
- **日期**: 2026-04-03
- **严重级别**: Medium

## 1. 问题现象
深度检索草稿中的“源数据”列表全部显示“网络连接问题”，无法返回真实网络检索文章。

## 2. 根本原因 (Root Cause)
- 默认搜索链路优先使用 Jina，但部署环境未配置 `JINA_API_KEY`，导致首选搜索引擎不可用。
- DuckDuckGo HTTP 回退链路虽然读取了 `HTTP_PROXY/HTTPS_PROXY`，但未真正通过代理发送请求，因此在受限网络环境下仍然直连失败。

## 3. 解决方案
- 新增服务端代理请求工具，在配置 `HTTP_PROXY` 或 `HTTPS_PROXY` 时通过代理发送 HTTP/HTTPS 请求。
- 调整搜索引擎选择逻辑，只有在显式启用且存在 `JINA_API_KEY` 时才走 Jina。
- 更新深度检索接口进度文案，使实际使用的搜索引擎与后端选择逻辑保持一致。

## 4. 预防措施
- 在环境示例中补充 Jina 与代理配置说明，减少部署误配。
- 通过日志输出当前是否具备 Jina 配置，便于快速判断搜索链路落点。
