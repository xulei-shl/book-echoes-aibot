# Prompt设计模板库 - AI调教实践与经验总结

## 概述

本文档记录了"书海回响"图书推荐系统中AI Prompt的设计、调优过程和实践经验，为图书馆学与AI技术融合提供重要的技术参考。

## 一、Prompt设计理念

### 1.1 设计原则

#### 1.1.1 专业性原则
**图书馆学专业要求**:
- 使用图书馆学专业术语和概念
- 体现中图法分类体系的专业认知
- 理解不同学科领域的特点和需求

**示例对比**:
```
通用Prompt: "请评价这本书的质量"
专业Prompt: "请从中图法分类体系角度，评估本书在TP181(自动化技术)分类中的学术价值和实用性"
```

#### 1.1.2 透明度原则
**决策过程可见**:
- 要求AI说明推荐理由的数据依据
- 明确引用具体的评分、人数、时间等数据
- 提供可追溯的推理链条

**透明度实现**:
```
推荐理由模板:
"基于以下数据推荐本书：
- 豆瓣评分：{rating}/10 ({vote_count}人评价)
- 近三月借阅：{borrow_count}次
- 主题匹配度：{category_match}%
推荐理由：{reasoning}"
```

#### 1.1.3 一致性原则
**评价标准统一**:
- 建立明确的评价维度框架
- 统一评分语言和表达方式
- 确保不同批次间的标准一致

### 1.2 设计方法论

#### 1.2.1 分层设计
**三级Prompt架构**:
1. **初评层**: 快速筛选，去除明显不合适选项
2. **决选层**: 精细比较，确定优先级
3. **终评层**: 综合评估，生成详细理由

#### 1.2.2 渐进优化
**迭代改进流程**:
```
版本1.0 → 效果测试 → 问题识别 → 版本2.0
     ↓         ↓         ↓         ↓
  基础功能   数据收集   问题分析   优化改进
```

#### 2.1.2 V1.0测试结果分析

### 3.1 竞争性评估机制

#### 3.1.1 多选一Prompt模板
```
【同类图书竞争性评估】

候选图书清单：
{candidates_list}

评估标准：

2. 读者价值: 对目标读者的实际帮助 (25%)
```

### 3.2 质量平衡算法

#### 3.2.1 自动晋级规则
```python
def auto_promotion_check(candidates, quota):
    """
    自动晋级检查：
    1. 数量≤配额，直接晋级
    2. 质量显著高于平均，自动晋级
    3. 特殊类别保护晋级
    """
    if len(candidates) <= quota:
        return candidates
    
    avg_quality = sum(c['quality_score'] for c in candidates) / len(candidates)
    promoted = []
    
    for candidate in candidates:
        if (candidate['quality_score'] > avg_quality * 1.3 or 
            candidate['special_category'] or
            candidate['novel_topic']):
            promoted.append(candidate)
    
    return promoted[:quota]
```

#### 3.2.2 平衡性保证
**多样性约束**:

### 5.3 失败案例分析

#### 5.3.1 典型失败案例

**案例1: 技术图书评估失败**
```
问题: AI过分依赖豆瓣评分，忽略了技术图书的专业特殊性
原因: Prompt中没有强调技术图书的评价特点
解决: 增加技术类图书专门评估维度
```

**案例2: 文学图书推荐偏差**
```
问题: AI倾向于推荐流行文学作品，忽略经典文学价值
原因: 初始Prompt没有强调文学的永恒价值
解决: 调整评价权重，突出文学价值和经典性
```

1. **增加领域专业知识**: 在Prompt中融入更多领域专业知识
2. **建立评价权重**: 针对不同类型图书设定不同评价权重
3. **引入专家知识**: 集成图书馆学专家的经验和判断标准
