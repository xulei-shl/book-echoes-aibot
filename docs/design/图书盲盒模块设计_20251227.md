# 图书盲盒模块设计文档

> 情感陪伴向交互模块 | 夜深/雨夜等寂静场景氛围

## 一、模块概述

图书盲盒是一个偏向情感陪伴的交互模块，为用户在夜深人静或寂静雨天等场景提供沉浸式书籍推荐体验。

### 核心特性
- **卡片式信息展示**：每次推荐三本书，垂直排列
- **左右布局交互**：左侧显示书目详情，右侧卡片悬停时飞入左侧
- **友好邻居原则**：模拟瓦尔堡图书馆的卡片前后关系
- **沉浸式体验**：根据标签组合切换背景图片和音乐
- **双重抽取模式**：随机抽取 + 情感标签筛选

## 五、"友好邻居"算法

模拟瓦尔堡图书馆的图像邻近原则，基于多维度计算书籍相似度：

```typescript
// 邻居相似度计算
function calculateNeighborScore(
  currentBook: BlindBoxBook,
  candidateBook: BlindBoxBook
): number {
  let score = 0;

  // 1. 情感标签重叠度 (权重: 40%)
  const emotionOverlap = candidateBook.emotionTags.filter(
    tag => currentBook.emotionTags.includes(tag)
  ).length / Math.max(currentBook.emotionTags.length, 1);
  score += emotionOverlap * 40;

  // 2. 场景标签重叠度 (权重: 30%)
  const sceneOverlap = candidateBook.sceneTags.filter(
    tag => currentBook.sceneTags.includes(tag)
  ).length / Math.max(currentBook.sceneTags.length, 1);
  score += sceneOverlap * 30;

  // 3. 阅读氛围相近度 (权重: 20%)
  if (candidateBook.readingMood === currentBook.readingMood) {
    score += 20;
  }

  // 4. 评分相近度 (权重: 10%)
  const ratingDiff = Math.abs(candidateBook.doubanRating - currentBook.doubanRating);
  score += Math.max(0, 10 - ratingDiff * 5);

  return score;
}

// 获取邻居书籍
function getNeighborBooks(
  currentBook: BlindBoxBook,
  allBooks: BlindBoxBook[],
  count: number = 2
): BlindBoxBook[] {
  return allBooks
    .filter(b => b.id !== currentBook.id)
    .map(book => ({
      book,
      score: calculateNeighborScore(currentBook, book)
    }))
    .sort((a, b) => b.score - a.score)
    .slice(0, count)
    .map(r => r.book);
}
```

## 八、沉浸式背景与音效

### 8.1 背景渲染策略

```typescript
interface AmbientConfig {
  baseImage: string;      // 底层封面模糊图
  overlayColor: string;   // 叠加色调
  vignetteIntensity: number; // 晕影强度
  particleEffect: boolean;   // 是否启用粒子效果
}

function AmbientBackground({ config }: { config: AmbientConfig }) {
  return (
    <div className="ambient-container">
      {/* 底层：封面模糊图 */}
      <div className="ambient-blur-layer">
        <Image src={config.baseImage} fill className="blur-3xl opacity-40" />
      </div>

      {/* 中间：色调叠加 */}
      <div
        className="ambient-overlay"
        style={{ backgroundColor: config.overlayColor }}
      />

      {/* 顶层：晕影遮罩 */}
      <div
        className="ambient-vignette"
        style={{
          background: `radial-gradient(circle, transparent 30%, ${config.overlayColor} 100%)`
        }}
      />

      {/* 粒子效果（可选） */}
      {config.particleEffect && <AmbientParticles />}
    </div>
  );
}
```

### 8.2 音乐播放策略

```typescript
function useAmbientAudio(config: TagConfig) {
  const audioRef = useRef<HTMLAudioElement>(null);
  const [isPlaying, setIsPlaying] = useState(false);
  const [volume, setVolume] = useState(0.3);

  // 标签切换时淡入淡出
  useEffect(() => {
    if (audioRef.current) {
      fadeAudio(audioRef.current, volume, 1000); // 1秒淡入/淡出
    }
  }, [config.musicTrack]);

  return { audioRef, isPlaying, setIsPlaying, volume, setVolume };
}
```

### 9.2 抽取逻辑

```typescript
function drawBlindBox(
  books: BlindBoxBook[],
  mode: 'random' | 'tag',
  selectedTags?: string[]
): BlindBoxBook[] {
  let pool = books;

  if (mode === 'tag' && selectedTags && selectedTags.length > 0) {
    // 按标签筛选
    pool = books.filter(book =>
      selectedTags.some(tag =>
        book.emotionTags.includes(tag) || book.sceneTags.includes(tag)
      )
    );
  }

  // 随机抽取 3 本（去重）
  const shuffled = [...pool].sort(() => Math.random() - 0.5);
  return shuffled.slice(0, 3);
}
```
