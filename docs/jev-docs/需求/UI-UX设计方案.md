# 📄 图书语义检索 Web 应用：UI 交互与动效设计需求文档

## 一、 项目概述

本项目旨在打造一个具有高度沉浸感与流畅视觉体验的图书语义检索 Web 应用。系统以一个宏大的 3D 纵深视效作为基底，通过精确的物理动效与跨状态的无缝过渡，打破传统页面“跳转”与“刷新”的生硬感，实现从“背景浏览”到“精准检索”再到“单本详读”的连贯空间体验。

**核心设计原则**：**Spatial consistency**（空间一致性）与 **Purposeful animation**（有目的的动画）。

## 二、 核心 UI 与排版规范

### 1. 3D 沉浸式动态背景层

- **基础视效**：由图书封面组成的阵列，在 Z 轴深度上呈现近大远小的 **Perspective**，并配合 **3D tilt**（rotateX 倾斜）形成类似星球大战片头字幕的斜向视场。
- **滚动行为**：整体图片流呈从底部向顶部消失点无限循环滚动的 **Marquee** 效果。
- **边缘柔化**：摒弃四周的硬性实体留白。容器全屏铺满，但在屏幕四周边缘叠加带有羽化渐变边缘的 **Mask**（遮罩），使图书在进入和离开屏幕时柔和隐现，降低视觉压迫感。
- **网格间距**：为抵消 3D 透视带来的视觉压缩，底层 Grid/Flex 布局需设定较大的初始间距。
- **微动效叠加**：为消除纯机械滚动的死板，每张图书封面需叠加微弱的随机 **Float**（上下悬浮）动画，赋予背景呼吸感与生命力。

### 2. 检索交互枢纽（Search Box）

- **初始排版**：绝对居中（约于屏幕高度 45% 视觉中心点），作为全屏 3D 隧道的视觉焦点。
- **UI 材质**：需与背景形成强对比。建议采用大圆角的重度毛玻璃（Backdrop-filter）面板，或采用复古图书馆借阅卡（Checkout card）质感搭配高饱和度 OKLCH 阴影，使其在 3D 空间中具有悬浮感。
- **进场动效**：页面初次加载时，检索框通过带有微小 **Spring** 弹性的 **Scale in** 与 **Fade in** 进场。

## 三、 交互状态与动效链路 (User Flow & Animations)

### 场景一：聚焦输入（Focus State）

当用户光标进入检索框准备输入时：

- **背景退让**：触发整体背景图层的 **Blur** 动画，模糊值平滑增加，同时稍微压暗背景亮度，使视觉焦点强制收束于检索框。背景滚动不停，但变为失焦状态。

### 场景二：执行检索（Search Trigger）

当用户敲击回车提交检索请求时：

- **检索框让位**：检索框触发 **Layout animation**，平滑缩小并向上滑动，停靠至屏幕顶部（约 `top: 5%` 位置），作为常驻搜索栏。
- **加载反馈**：在结果返回前的等待期，搜索栏下方浮现 **Typewriter** 效果的加载提示语（如：“正在提取语义特征...”），掩盖大模型的网络延迟。

### 场景三：结果呈现与状态闭环（Result & Reset）

当后台返回检索结果时：

- **无缝结果提取**：命中的目标图书封面通过 **Shared element transition** 从 3D 背景层中直接“脱离”出来，跨越空间轴，平滑落位到下方 2D 画廊网格排版中，建立严密的 **Continuity transition**。
- **重置检索**：当用户清空检索条件时，检索框通过 **Direction-aware transition** 原路滑回屏幕中心；画廊中的图片则反向飞回，重新融入背景阵列中。

### 场景四：图片操作交互（Hover & Click）

针对场景内出现的所有图书封面（无论在背景层还是画廊层）：

- **悬停阅读（Hover）**：当鼠标悬停于背景某图片时，利用 **Interruptible animation** 将 **Marquee** 容器的滚动速度（Velocity）平滑降至 0。移开光标后，滚动速度带有缓动地平滑恢复，严禁急刹车式的突变。
- **点击确认（Press）**：每次点击图片，必须触发 **Press / Tap feedback**，伴随极短促的物理微缩放反馈，提升操作跟手感。

### 场景五：详情页跳转（Navigation to Detail）

当用户确认并点击某本图书进入详情页时：

- **路由过渡**：废弃传统的白屏刷新，采用原生 API 或框架支持的 **View transition**。
- **元素飞行**：被点击的封面图再次触发跨页面的 **Shared element transition**，从当前位置直接飞出、放大，并无缝形变为详情页的主视觉封面；详情页的文本等其他元素则通过 **Slide in** 或 **Fade in** 顺滑入场。

## 四、 性能与技术约束 (Performance Constraints)

为了支撑上述复杂的大面积动态效果，技术实现必须遵循以下规范：

1. **Frame rate (FPS) 保障**：核心动画必须保证 60fps - 120fps。
2. **Hardware acceleration（硬件加速）**：所有位移与形变动画（包括背景的 Marquee 和飞出的 Transition）必须严格使用 `transform`（如 `translate`, `rotateX`, `scale`）和 `opacity` 属性来实现，确保交由 GPU 渲染。
3. **避免 Jank 与 Layout thrashing**：针对将要持续发生变化的元素，提前应用 CSS `will-change: transform, opacity` 属性进行图层提升（Compositing），严禁在滚动循环中引发浏览器的重排（Reflow/Layout）。
