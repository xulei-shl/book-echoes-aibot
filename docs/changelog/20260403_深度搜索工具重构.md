# 深度搜索工具重构 - 2026-04-03

## 概述

按照 `@docs/changelog/search-docs/深度搜索工具重构.md` 的需求文档，将原有的 DuckDuckGo + Jina Search 搜索链路重构为 Tavily + Exa MCP 方案。

## 变更内容

### 1. 新增文件

| 文件 | 说明 |
|------|------|
| `src/core/aibot/tavily/tavilyResearcher.ts` | Tavily Search API 搜索实现 |
| `src/core/aibot/exa/exaMcpResearcher.ts` | Exa MCP (WebSocket) 搜索实现 |
| `src/core/aibot/jina/jinaContentExtractor.ts` | 使用 jina.ai 提取网页全文内容 |

### 2. 修改文件

| 文件 | 变更内容 |
|------|----------|
| `src/core/aibot/types.ts` | 新增 `TavilySnippet`, `ExaSnippet`, `TavilySearchOptions`, `ExaSearchOptions` 类型；更新 `WebSearchSnippet.source` 为 `'tavily' \| 'exa'` |
| `src/core/aibot/searchConfig.ts` | 移除 Jina 配置，改为 Tavily/Exa 配置检测函数 |
| `src/core/aibot/webSearchService.ts` | 重构搜索链路：Tavily → Exa MCP 回退 → jina.ai 内容提取 |
| `src/core/aibot/researchWorkflow.ts` | 使用 `performWebSearch` 替代旧的 `researchWithDuckDuckGo` |
| `app/api/local-aibot/deep-search-analysis/route.ts` | 更新调试日志字段名 (useJina → useTavily) |

### 3. 删除文件

| 文件 | 说明 |
|------|------|
| `src/core/aibot/mcp/duckduckgoResearcher.ts` | 旧的 DuckDuckGo MCP 实现 |
| `src/core/aibot/jina/jinaResearcher.ts` | 旧的 Jina Search 实现 |

## 搜索链路架构

```
performWebSearch(query)
 │
 ├─► shouldUseTavilySearch() ── 有 TAVILY_API_KEY? ──► researchWithTavily()
 │                                                          │
 │                                                         ▼
 │                                                  成功返回结果
 │                                                          │
 │                                                         ▼
 │                                                  失败则回退
 │
 └─► researchWithExaMcp() ◄─── WebSocket: https://mcp.exa.ai/mcp
       │
       └─► 失败 → 返回错误占位数据

获取候选 URL 列表
 │
 ▼
 https://r.jina.ai/{url} 获取网页全文
 │
 ├─► 成功 → 写入 result.content
 │
 └─► 失败 → 使用原搜索摘要 (snippet)

 ▼
 传入后续 LLM 分析步骤
```

## 配置

| 环境变量 | 说明 |
|----------|------|
| `TAVILY_API_KEY` | Tavily API 密钥 (必填) |
| `EXA_API_KEY` | Exa API 密钥 (可选，无密钥也可使用 MCP) |
