# 开发变更记录

- **日期**: 2026-04-02
- **任务**: AIBot 弹窗样式向 `AboutOverlay` 设计语言对齐，并补充检索结果操作区样式 handoff

## 1. 变更摘要
本次修改仅涉及样式，不调整交互逻辑、状态流转和接口行为。

目标是将 AIBot 相关界面的视觉风格，从原先较通用的深色圆角卡片样式，统一到 `components/AboutOverlay.tsx` 所代表的这一套更明确的设计语言，便于后续其他页面继续复用。

## 3. 这次确定下来的设计风格

### 3.1 整体基调
后续相关页面如需延续本次风格，优先遵循以下关键词：

- **深色底 + 金色线框**
- **弱圆角甚至无圆角，强调结构线条而不是卡片感**
- **轻拟物减弱，避免厚重阴影和大面积发光**
- **更像展陈面板 / 档案视图，而不是常规 chat UI**
- **局部用 monospace 和 tracking 增强“系统面板感”**

### 3.2 不再优先使用的旧风格
后续新页面尽量避免继续扩散以下样式倾向：

- 大量 `rounded-lg` / `rounded-xl` / `rounded-2xl`
- 深色背景上再叠加明显卡片块
- 灰边框 `#343434` 为主、金色只作为点缀
- 常规 SaaS 风格 tooltip / 按钮
- `font-body` 主导所有操作按钮和状态标签

## 4. 视觉语言规则

### 4.1 容器
推荐容器基调：
- 背景：`bg-[#1a1a1a]/90` 或同系深色半透明背景
- 边框：`border border-[#C9A063]/20` 或 `/30`
- 模糊：`backdrop-blur-xl`
- 尽量少用 box-shadow，重点依靠边框、层次和留白

### 4.2 结构装饰
当页面是“主弹窗 / 主面板 / 关键浮层”时，可复用：
- 四角 corner accents
- 底部 status bar
- 大字号低透明 watermark
- 顶部标题栏 + 左侧小方块标记

注意：不是所有小组件都需要全部装饰。小组件只继承颜色、边框、字体和按钮体系即可。

### 4.3 按钮
本次确定的按钮方向：

#### 主按钮
- 金色底：`bg-[#C9A063]`
- 深色字：`text-[#1a1a1a]`
- 边框保留：`border border-[#C9A063]`
- hover 时反转为透明底 + 金色字

#### 次按钮
- 透明底 + 金色边框
- `border-[#C9A063]/30`
- hover 填充金色背景，文字切深色

#### 辅助按钮
- 透明底 + 更弱的金色边框
- 文本可用 `text-[#C9A063]/70` 或 `text-[#E8E6DC]`
- 不建议继续使用灰边圆角按钮体系

#### 字体
- 操作按钮优先 `font-mono tracking-wider`
- 信息说明、正文继续用 `font-info-content`
- 避免按钮继续大量使用 `font-body`

### 4.4 Tooltip
本次 tooltip 风格原则：
- 深色底：`bg-[#1a1a1a]`
- 金色浅边：`border border-[#C9A063]/20`
- 去掉厚阴影依赖，减少“气泡组件库感”
- 使用更克制的说明面板风格
- 正文建议 `font-info-content text-xs`
- 箭头颜色与边框体系保持一致

### 4.5 滚动区域
统一优先使用 `about-overlay-scroll`，不要再为 AIBot 单独扩散一套滚动条审美。

滚动条风格应保持：
- 细滚动条
- 金色系 thumb
- 透明 track
- 和主面板一致的轻复古质感

### 4.6 运行中状态 / 进度日志
本次确认：运行过程中的进度日志，不建议只保留静态 spinner + 一行文字。

推荐方向：
- 用**克制的连续动效**表达“系统正在处理中”，而不是只靠静态提示
- 动效优先使用金色体系内的弱呼吸、微脉冲、轻扫光
- 动效强度保持克制，避免明显跳动、夸张弹性或高饱和发光
- 整体气质应更接近“系统面板 / 档案处理流”，而不是通用 SaaS loading 提示

注意：动效的目的不是吸引注意力，而是持续告知“此步骤仍在运行中”。如果已经完成或失败，应切换到明确的完成/错误状态，而不是继续保留运行中动效。

## 6. 后续页面复用建议
如果后续要继续改其他页面，建议优先直接对齐 `AboutOverlay`，而不是再从当前页面二次猜测。可按下面顺序套用：

1. **先定容器**：背景、边框、模糊、四角、标题栏、状态栏
2. **再定按钮**：主按钮 / 次按钮 / 辅助按钮三档
3. **再定字体**：标题偏 `font-mono` 或展示字体，正文 `font-info-content`
4. **最后统一 tooltip、滚动条、列表项边框**

这样更容易保持全站一致，不会每个页面都只“像一点点”。

## 7. 可直接复用的判断标准
后续设计 review 时，可快速用下面几条判断是否偏离本次风格：

- 看起来是否仍像“普通 SaaS 面板”？如果是，说明还不够统一。
- 是否还在大量使用圆角卡片？如果是，说明结构语言不够硬朗。
- 金色是否只是点缀，而不是主结构色？如果是，说明还没对齐。
- 操作按钮是否仍像默认组件库按钮？如果是，建议重做。
- tooltip 是否像系统说明牌，而不是通用黑色气泡？如果不是，建议调整。

## 8. 注意事项
- 本次 handoff 记录的是**样式方向**，不是抽象组件规范。
- 后续如果要进一步系统化，建议再抽公共样式或设计 token；本次暂未做抽象，避免为了样式统一而引入额外逻辑改动。
- 如果未来继续统一更多页面，建议优先围绕 `AboutOverlay` 这套视觉语言扩展，而不是回退到旧的 AIBot 卡片风格。

## 9. 跨页面导航按钮同步落地 (追记)

为了保证视觉连贯性，除 AIBot 本身外，平台内的几组核心主导航条及主行为按钮也已同步更新至本次的“深色底 + 金色线框 + 弱圆角”设计语言。

**核心变更逻辑**：
- 废弃了原本依赖全局组件类的 `.btn-random` 大圆角（`rounded-full`）样式，向强调硬朗方正线条的结构化面板靠拢。
- 移除了操作区泛用的 `font-body`，转而使用 `font-mono tracking-wider` 增强终端系统命令仪表的氛围感。

**具体同步落地的组件与页面位置**：
1. **首页大屏区 (Home Screen)**
   - 按钮：`Enter Issue` 主行动点
   - 改动：定位为**主按钮**规格表现，采用全金色底板（`bg-[#C9A063]`）及深灰字字体重构，Hover时触发反相态透明感。
   - 文件：`components/HomeHero.tsx`

2. **核心页头导航区 (Global Header)**
   - 覆盖页面：Archive页（首页、漫步、关于），各个单期画板打卡页（首页、往期、漫步、导读）
   - 改动：定位为**次按钮**规格表现，使用完全透明底结合微金线框 `border-[#C9A063]/30`，Hover触发底色填充变暗。
   - 文件：`components/Header.tsx`

3. **随机漫步专页 (Random Walk)**
   - 按钮：顶部导航的 `首页`、`往期` 
   - 改动：直接应用同样的基础层 Tailwind 线框工具类覆盖原有逻辑，按钮内置图标与功能行为不变。
   - 文件：`components/RandomMasonry.tsx`

4. **图书信息拓展面板 (InfoPanel)**
   - 按钮：左右切换箭头、三点菜单，以及悬浮展开的“关闭”、“下载”、“全部下载”操作项
   - 改动：将其彻底从旧版的圆形 (`btn-random--circle`) 和胶囊形态重构为了直边线框的“系统行动仪”样式面板，移除 `rounded-full` 并全量应用 `w-12 h-12` 和 `w-full` 直边规格及深色毛玻璃底。
   - 文件：`components/InfoPanel.tsx`

## 10. AIBot 组件内部草稿与进度面板样式对齐 (追记)

为了保证 AIBot 问答与文献分析流中的各个交互节点视觉一致，移除了旧版的圆角高光面板体系，以下组件已被纳入本次的统一规范（深色毛玻璃、金色线框、去圆角化以及全系 `font-mono tracking-wider` 控件字体）：

1. **`DeepSearchDraftMessage.tsx` (深度检索草稿展示)**
   - 彻底移除了带有圆角的粗边框容器，替换为 `bg-[#1a1a1a]/90 backdrop-blur-xl` 的深色毛玻璃系统面板。
   - 分类梳理了操作区的所有按钮，遵循“主按钮金色实心、次按钮透明带框”的交互法则，移去了原有不协调的 `bg-[#1B1B1B]` 弱交互悬停样式。
   
2. **`DocumentAnalysisDraftMessage.tsx` 与 `DraftConfirmationDisplay.tsx` (文档分析报告草稿交互窗)**
   - 重配了顶层容器与所有确认层背景。
   - 移除不一致的绿灯色块 (`bg-green-500`) 及环形动效标识，由规整统一的、带边缘闪烁感的小方点 (`w-2 h-2 bg-[#C9A063]`) 代替。
   - 操作按钮全面对齐了系统规格。

3. **`ProgressLogDisplay.tsx` 与 `DocumentAnalysisProgressMessage.tsx` (分析过程运行日志)**
   - 同步修正了列表折叠栏与外部框的配色及模糊特性。
   - 移除部分残余的大面积深色背景快，规范了进程动画在“处理流”状态下的视觉效果（保留弱呼吸动画及轻扫彩溢出感，去除了原本附带的强圆角限制）。
